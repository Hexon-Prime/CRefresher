To write and run C code in Visual Studio Code, you must install Microsoft's C/C++ extension along with an external C compiler. The extension provides syntax highlighting, IntelliSense, and debugging, while the compiler translates your code into an executable program.

1. Install a C Compiler

VS Code does not include a built-in compiler, so you must set one up for your operating system first:
• Windows. Install the MinGW-w64 toolchain via MSYS2 by running pacman -S --needed base-devel mingw-w64-ucrt-x86_64-toolchain in the MSYS2 terminal. Afterward, add the compiler's bin folder (typically C:\msys64\ucrt64\bin) to your Windows system PATH environment variable.
• macOS. Open the Terminal app and run xcode-select --install to install the Clang compiler and Xcode Command Line Tools.
• Linux. Open your terminal and install the GNU Compiler Collection (GCC) using your package manager, such as sudo apt update && sudo apt install build-essential gdb on Ubuntu or Debian.
• Verify Installation. Open a new terminal or command prompt and run gcc --version to confirm your system recognizes the compiler.

2. Install VS Code Extensions

Next, add C language support inside VS Code:
• Open the Extensions View. Launch VS Code and click the Extensions icon on the left sidebar, or press Ctrl+Shift+X (Cmd+Shift+X on Mac).
• Install the C/C++ Extension. Search for C/C++ in the marketplace and click Install on the official C/C++ extension by Microsoft.
• Optional Code Runner. Search for and install the Code Runner extension if you want a quick one-click way to execute single files without configuring debug tasks.

3. Write and Run Your C Program

Once your compiler and extensions are ready, follow these steps to test your setup:
• Create a Workspace Folder. Open a dedicated folder in VS Code via File > Open Folder.
• Create a C File. Click the New File icon in the Explorer sidebar and name it hello.c. Make sure the file ends with the .c extension.
